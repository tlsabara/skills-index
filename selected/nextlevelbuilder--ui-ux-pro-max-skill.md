# nextlevelbuilder/ui-ux-pro-max-skill

## O que é

Skill de design com base local em CSV (estilos, paletas, fontes, gráficos, guidelines de UX), consultada por scripts Python só de stdlib, sem rede. MIT.

## Por que é útil

Tem `stacks/vue.csv` (Composition API, `<script setup>`) e `html-tailwind`, e um checklist pré-entrega (contraste, foco, reduced-motion, breakpoints) que serve de base para diretivas de UI de um projeto.

## O que aproveitar

Só a pasta `ui-ux-pro-max`, por projeto.

## Como instalar

Por projeto, com `uipro init --ai claude`. Nunca global.

## Riscos e custos

- O plugin do marketplace instala 7 skills (brand, slides, banner-design etc.) que competem nos gatilhos.
- Viés para landing page de marketing; pode brigar com o padrão visual de um sistema interno.
- Upsell da versão premium.
