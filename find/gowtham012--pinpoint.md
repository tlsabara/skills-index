# gowtham012/pinpoint

## O que é

Extensão Chrome com MCP e hooks que manda ao agente o componente clicado na página, lendo o `__file` do Vue. É o equivalente ao [react-grab](../deprecated/aidenybai--react-grab.md) que funciona com Vue.

## Onde encontrei

Busca por alternativa ao react-grab para Vue. Muito novo (4 estrelas); só com cautela.
