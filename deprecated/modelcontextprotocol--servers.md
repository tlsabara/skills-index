# modelcontextprotocol/servers

## O que é

Repositório de servidores MCP de referência, didáticos: Everything, Fetch, Filesystem, Git, Memory, Sequential Thinking e Time. GitHub, GitLab, Postgres, Slack e outros foram para `servers-archived`; a lista geral agora é o registry.modelcontextprotocol.io.

## Por que foi desclassificado

Cada servidor repete algo nativo: Fetch = WebFetch, Filesystem e Git = Read/Edit/Bash, Time = `date`, Memory = CLAUDE.md e memória do agente, Sequential Thinking = raciocínio estendido. Só serve como código de exemplo para escrever um MCP próprio.
